# Man Cave Explorer

A browser-based roguelike dungeon crawler. No dependencies, no build step — just open `index.html` and play.

## How to Play

Open `index.html` in any modern browser.

### Controls

| Key | Action |
|---|---|
| `WASD` / Arrow Keys | Move & attack adjacent monsters |
| `E` | Descend stairs (`>`) |
| `R` | Rest (recover 1 HP, costs a turn) |
| `Q` | Quaff a health potion |

### Goal

Descend through **10 procedurally generated floors** of an underground cave. Fight monsters, collect loot, level up, and survive to the bottom.

### Symbols

| Symbol | Meaning |
|---|---|
| `@` | You |
| `#` | Wall |
| `.` | Floor |
| `>` | Stairs down |
| `~` | Water (impassable) |
| `$` | Gold |
| `!` | Health Potion |
| `/` | Weapon |
| `]` | Armor |
| `*` | Power Crystal (permanent stat boost) |
| Letters | Monsters (r=Rat, s=Snake, g=Goblin, o=Orc, D=Dragon, etc.) |

### Tips

- Explore each floor for items before descending — you can't go back up.
- Potions are precious. Save them for tough fights.
- Power Crystals give permanent stat boosts — always grab them.
- Weapons and armor auto-equip if they're stronger than your current gear; otherwise they sell for gold.
- Resting recovers HP slowly but monsters still move, so find a safe spot.
- The Lich King and Cave Dragon await on the final floors. Come prepared.
