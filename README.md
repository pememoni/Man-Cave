# Neko Cave ~ A Kawaii Dungeon Adventure

A browser-based roguelike dungeon crawler starring a cute Japanese cat. Emoji-based visuals, yokai monsters, and kawaii vibes. No dependencies, no build step — just open `index.html` and play.

Works on desktop and mobile (touch controls included).

## How to Play

Open `index.html` in any modern browser, or deploy to GitHub Pages.

### Controls

**Desktop:**

| Key | Action |
|---|---|
| `WASD` / Arrow Keys | Move & attack adjacent yokai |
| `E` | Descend stairs |
| `R` | Nap (recover 1 HP, costs a turn) |
| `Q` | Drink warm milk (health potion) |

**Mobile:** On-screen D-pad + action buttons, or swipe on the map.

### Goal

Guide a brave kitty through **10 procedurally generated floors** of yokai-infested caves. Fight monsters, collect loot, level up, and reach the bottom to win!

### What You'll See

| Emoji | Meaning |
|---|---|
| Cat face | You (Neko!) |
| Rock | Wall |
| Castle | Stairs down |
| Water drop | Water (impassable) |
| Money bag | Gold |
| Milk | Warm Milk (health potion) |
| Swords | Weapon |
| Shield | Armor |
| Sparkles | Spirit Orb (permanent stat boost) |

### Yokai Bestiary

| Floors | Monsters |
|---|---|
| 1-4 | Nezumi (rat), Tanuki, Komori (bat) |
| 2-6 | Kappa, Dokuro (skull) |
| 3-7 | Oni |
| 5-9 | Tengu, Dark Kodama, Yurei (ghost) |
| 7-10 | Jorougumo (spider) |
| 9-10 | Ryu (dragon) |
| 10 | Yokai King (final boss) |

### Tips

- Explore each floor for items before descending — you can't go back up.
- Warm milk is precious. Save it for tough fights, nya~
- Spirit Orbs give permanent stat boosts — always grab them!
- Weapons and armor auto-equip if stronger; otherwise they sell for gold.
- Napping recovers HP slowly but yokai still move, so find a safe spot.
- The Ryu and Yokai King await on the final floors. Come prepared!
